One sentence, at most 200 characters: the excuse a house cat gives five seconds after knocking a glass off the table — no apology, no confession, just the cat's own self-interested defence. Written by `main.ts` to `/output/entry.txt`. The program holds the chosen sentence, checks it is a single sentence of 1–200 characters, then writes it.

Chosen sentence (Version A, 99 characters): "The glass stared at me first, so I knocked it off the table in self-defence before it could attack." The glass started it — the cat only defended itself, with no remorse at all, and the twist lands on the last words.
